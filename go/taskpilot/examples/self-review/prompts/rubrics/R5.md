R5 -- Testability without leaking.

Flag production code that exposes internals purely for tests, or global state
that tests must reset:

- Exported-for-test-only symbols: functions/fields/vars that exist only because a
  test reaches for them. Prefer testing through the public boundary, or move the
  seam into a `_test.go` helper.
- Package-level mutable `var` state that tests must save/restore, or that couples
  tests through shared globals. Prefer dependency injection or per-call state.
- Test-only hooks, flags, or branches compiled into production paths.

The INVERSE also fails this axis: do NOT accept a change that "makes testing
easier" by adding indirection or exposing internals -- that is a backward ratchet
on complexity (R1). Test seams in production must stay at zero.

Countable proxy: package-global mutable var count DOWN; exported-for-test-only
symbols -> 0; test-only seams in production -> 0.
