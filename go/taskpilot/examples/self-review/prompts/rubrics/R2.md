R2 -- Single source of truth (semantic dedup). WHOLE-REPO axis.

For each function/block in this file, GREP the codebase (ripgrep) for similar or
related functionality and flag SEMANTIC duplication -- the same fact or logic
encoded in more than one place, even when the text differs.

Look for:

- The same constant/literal (a format string, magic number, path fragment, error
  message) written independently in multiple places. The single-source fix is one
  named declaration.
- Two functions that compute the same thing by different means, or parallel
  implementations that must agree but are maintained separately.
- A fact derived independently in two layers (e.g. a hash domain, a default
  limit) that could drift.

Flag when the copies could plausibly DRIFT -- an independent edit to one would
need a matching edit to the other to stay correct. Pure textual coincidence with
no shared contract (copies that are not required to agree) does NOT qualify.

Evidence is REQUIRED: cite every grep match (`file:line`) you relied on, and
state the fixTarget that becomes the single source.

Countable proxy: independent encodings of one fact -> 1; repeated-literal count
DOWN.
